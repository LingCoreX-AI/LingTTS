# 英语模型资源与性能

英语模型1.1.0，SDK0.3.0-rc1正式发布版。16kHz、80Mel、hop160，模型参数1,429,882。
声学INT8主干保留较小的FP32嵌入/条件投影；声码器使用INT8主干和INT32谱头。

| 资源 | 大小 |
|---|---:|
| 合并模型 `lingtts.bin` | 1,611,544 B（1.61 MB） |
| 精简例外词典 `lingtts_fe.bin` | 94,611 B |
| 可选完整例外词典 | 2,159,231 B |
| LTS规则表（编入库，位于Flash） | 153,030 B |
| 无PSRAM英语引擎工作区 | 210,912 B，约206KiB |

工作区不含调用任务栈、I2S、Wi-Fi/HTTP服务及应用自己的队列。speak期间不分配内存。
英语建议最大64音素、B32；长句按词边界切分。带PSRAM模式还需容纳复制的模型和词典。

2026-11-26实测：ESP32-S3，240MHz，DIO80MHz、64KiB data cache，S3 NN优化；
12种真实文本输入，完整C前端到PCM；常规组11个输入，53.36秒输出。

| 完整文本，无PSRAM | 实测 |
|---|---:|
| RTF中位数 | 0.580 |
| 总计算/总音频时长 | 0.584 |
| 首PCM中位数 | 233ms |
| 内部堆最低剩余 | 约65KiB（该测试应用） |

RTF扣除了PCM回调等待，仍包括必要计算。首PCM不等于实际出声延迟。
另做同板、B32、不计前端的配对计算测试：模型/工作区都在PSRAM时，中文0.436、英文0.373；
模型在Flash且工作区内部RAM时，中文0.676、英文0.542。该配对组每语言两个输入、
各3次性能运行；不能与上述完整文本数字或含Wi-Fi的热点例程混称。

同一板上六句PCM在量化速度优化前后逐字节相同；用户已认可的三句I2S播放效果保留。
SDK中的hello/web_demo为发布集成例程；其独立打包构建检查与新的热点实机验收范围
以Release随附的验证清单为准。没有把历史中文版的30分钟测试算成英语版已通过。
