首段 PCM 延迟：板端收到完整请求至首次生成音频，不含浏览器传输、播放预缓冲和扬声器延迟。RTF = 文本前端与合成处理耗时 ÷ 音频时长，扣除音频回调时间（含队列等待），仍包含调度影响；越小越快。播放任务耗时包含预缓冲及保守的 DMA 尾部排空时间。内存为运行期间采样的堆数据，包含 Wi-Fi 和网页服务，不代表 TTS 独占内存或精确瞬时峰值。
