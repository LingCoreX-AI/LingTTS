# LingTTS 0.2.0-rc2 社区预览版：语速调节

新增运行时语速设置、示例配置和热点演示网页语速选择。

- SDK：创建前设置 `cfg.speed`，或在两次朗读之间调用 `lingtts_engine_set_speed()`；默认 1.0，建议 0.5～2.0 倍。非法值被拒绝并保留原语速。
- hello：menuconfig → LingTTS hello → Speech speed percent，范围 50～200，默认 100。
- 热点演示固件：网页选择 0.5/0.8/1.0/1.2/1.5/2.0 倍语速；每次提交独立设置，播放中保持不变。
- 演示 API：`POST /api/speak` 继续接收 UTF-8 纯文本，可选请求头 `X-LingTTS-Speed`；省略时为 1.0，非法值返回 400，播放中提交仍返回 409。状态返回本次 `speed`。
- 调速通过模型音素时长实现，输出与 I2S 采样率始终为 16 kHz。核心模型与词典不变。
- 新接口需要 rc2 预编译库；升级时请整体替换组件并重新构建工程，勿混用头文件和旧库。
