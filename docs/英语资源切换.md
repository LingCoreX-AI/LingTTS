# LingTTS 英语资源 1.1.0

这是 LingTTS 更新中的可选英语资源包，使用通用 SDK 0.3.0-rc1 或更新的兼容版本，不是独立 SDK。
美式英语女声 A，16 kHz 单声道。`hello` 和 `web_demo` 共用代码，自动识别模型与词典的语言。

包内 `assets/lingtts.bin` 为模型，`assets/lingtts_fe.bin` 为精简词典；两者必须成套使用。
`lingtts_fe_full.bin` 是可选完整词典，默认不加载。归档及包内文件分别提供 SHA-256 校验。
旧版 0.2.0-rc2 SDK 不支持英语资源，请先升级通用 SDK。

## 构建

把资源包解压在通用 SDK 的 `resources/` 下，从 SDK 根目录运行：

```sh
idf.py -C examples/hello -B build/hello-en -D LINGTTS_ASSET_DIR="$PWD/resources/lingtts-resources-en-US-1.1.0-community/assets" build
idf.py -C examples/hello -B build/hello-en -p /dev/ttyUSB0 flash monitor
```

网页例程同理，将 `hello` 换为 `web_demo`。Windows PowerShell 将 `$PWD` 路径改成实际的绝对路径，串口改为实际 COM 号。
也可先备份通用 SDK 的中文 `assets/`，再同时替换模型和精简词典，沿用原构建命令。
无需语言编译开关，也不修改示例代码。网页按设备返回的语言自动切换默认文本。

## 已安装通用体验固件时

同一版本的通用体验固件无需更换 app。按该固件 `flash.json` 的实际偏移写入模型和词典后重启，自动切为英语。
本次 N16R8 通用热点固件的偏移为模型 `0x200000`、词典 `0x400000`：

```sh
python -m esptool --chip esp32s3 --port COM5 write_flash 0x200000 assets/lingtts.bin 0x400000 assets/lingtts_fe.bin
```

先核对 `flash.json`。以上偏移不适用于 hello 或其他产品固件；不要覆盖分区表、NVS 或授权区。
恢复中文时将两个分区同时换回通用 SDK 自带的资源。现阶段选择一套语言资源，不代表混合朗读或同时驻留自动切语种。

完整词典 2,159,231 字节，web_demo 的 3 MB 词典分区足够；hello 需扩大分区及 Flash 配置。
本版一个英语音色；专名和多音词仍可能误读。示例与核心/资源分别许可，商业部署需书面授权，见 LICENSE.md。
