# 通用 LingTTS SDK：英语资源集成

通用 SDK 0.3.0-rc1，英语资源1.1.0，ESP32-S3，ESP-IDF5.5.6。

额外下载 `lingtts-resources-en-US-1.1.0-community.tar.gz`，将其 `assets/` 指定为 `LINGTTS_ASSET_DIR`，或同时替换默认中文模型和词典。
同一份 hello/web_demo 自动识别资源，无需语言编译开关。旧版0.2.0-rc2库不支持英语资源。

1. 复制 `components/lingtts` 到自己的组件目录，依赖 `lingtts`，包含 `lingtts_engine.h`。
2. 保留 `lingtts_model`、`lingtts_fe` 两个 data 分区；名字用于自动查找。模型分区2MB足够，
   精简词典分区至少96KiB。示例 `hello` 为4MB Flash，`web_demo` 为16MB。
3. 在 `project()` 之后调用 `lingtts_flash_assets("${CMAKE_CURRENT_LIST_DIR}/assets")`。
   资源仍叫 `lingtts.bin`、`lingtts_fe.bin`；`idf.py flash` 会一并烧录，不需要激活文件。
4. 用 `lingtts_engine_default_cfg` 初始化；英语设 `max_tokens=64`、默认 `block=32`。
   使用 `lingtts_engine_create`、`lingtts_engine_speak`、`lingtts_engine_stop` 和 destroy。

默认 PSRAM 配置会将从分区加载的资源复制到 PSRAM。没有 PSRAM 时设
`cfg.mem=LINGTTS_MEM_INTERNAL`，工作区约206KiB，直接读取Flash资源。
显式传入 `cfg.model/frontend` 指针时，库不再复制资源；这些16字节对齐的地址须在
引擎销毁前持续有效。模型与词典版本必须配套。

I2S输出16kHz mono16。直接在PCM回调里阻塞写I2S时，使用至少400ms DMA，避免块间断供；
也可以像web_demo一样用独立播放任务及PCM队列。首PCM时间不等于扬声器出声时间。

`lingtts_engine_speak`在调用任务中阻塞，按段流式回调。其他任务可调用stop，或由PCM
回调返回非0停止；下次speak可恢复。只有一个任务执行speak/set_speed/set_voice。
不同实例及语言也应串行，算子使用共享scratch。语速建议0.5～2.0，不改变采样率。

本包只有一个英语音色，不使用中文 `.ltv` 音色覆盖。英语引擎的
`lingtts_engine_tts()`返回NULL，查询英语状态请调用`lingtts_engine_get_english_stats()`。
普通 `lingtts_engine_get_mem()`继续返回内存布局；英语的tts_arena包含整个英语引擎工作区。

完整版词典`lingtts_fe_full.bin`为2,159,231B，超过hello默认词典分区。使用时改名为
`lingtts_fe.bin`并把分区扩大到至少2.1MiB、Flash扩大到8MB以上；web_demo的3MB词典分区
已足够。完整词典使用同一LTS回退算法，主要增加不规则词/姓名的明确读法。

示例分区和发布体验包仅适用于自己的完整安装。正在运行的助手/产品可能采用其他
分区布局，请先备份，以对应包内flash.json或flasher_args.json为准。只改应用可用app-flash。
