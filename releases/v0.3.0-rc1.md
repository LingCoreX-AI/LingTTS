# LingTTS 0.3.0-rc1：新增英语语言资源

这是 LingTTS 的统一更新：同一套 SDK、hello 和 web_demo 支持中文或英语资源，加载资源后自动识别语言。
通用 SDK 和体验固件默认保持中文女声 A，新增英语资源 1.1.0（美式英语女声 A）。

下载：

- `lingtts-sdk-0.3.0-rc1-community.tar.gz`：通用预编译组件、默认中文资源、共用示例与文档。
- `lingtts-demo-0.3.0-rc1-n16r8-community.tar.gz`：通用 N16R8 热点固件、默认中文资源及烧录脚本。
- `lingtts-resources-en-US-1.1.0-community.tar.gz`：需要英语时额外下载，成套替换模型与词典，无需更换 app 或重写示例。
- 每个归档提供 `.sha256`，包内另有 `SHA256SUMS`。

英语资源需要本次更新的通用引擎；不能直接放进 0.2.0-rc2 的旧中文引擎。现有中文发布及女声 B 资源仍保留。
通过 `LINGTTS_ASSET_DIR` 指定资源目录，或者备份后替换默认 `assets/`。API 和 PCM 格式保持一致，输出 16 kHz 单声道。
当前为单套资源选择，未实现运行时双包管理或中英混合朗读。英语一个音色，专名及多音词仍可能读错。

热点默认 `LingTTS-Demo` / `lingtts-demo`，地址 `http://192.168.4.1`，音量 50%。ESP-IDF 5.5.6。
中、英文 hello 与通用热点固件已通过 ESP32-S3 实机验收：语言资源识别、播放、调速与输入校验正常，见包内 VALIDATION.md 及[验证说明](https://github.com/LingCoreX-AI/LingTTS/blob/v0.3.0-rc1/releases/v0.3.0-rc1-validation.md)。
核心与资源沿用社区许可，商业部署需书面授权。

English: a single LingTTS update adds optional English resources. The common SDK and
examples detect the loaded language. Chinese resources remain the default; English
users replace the model and frontend together. The old SDK cannot load English models.
