# LingTTS 0.3.0-rc1 候选包验证

2026-11-26，ESP32-S3 N16R8、ESP-IDF 5.5.6，MAX98357A：BCLK15 / WS16 / DATA7。
本次板测使用发布候选包；公开下载的归档完整性另行核对，不重复记为板测。

- 实际 SDK 归档解压后独立构建 hello / web_demo；分别换入中文、英语资源。每个示例两种资源下的应用二进制完全一致。
- 两种语言的 hello 各三句实机播放，全部返回0、I2S断供0次。PSRAM配置，中文RTF0.419～0.440、首PCM271～303ms；英语RTF0.390～0.397、首PCM152～190ms。
- 候选热点固件实际烧录并连接电脑：中文资源识别为zh-CN，成套替换模型与词典后识别为en-US；替换语言时没有改写应用。
- 浏览器通过真实热点页面检查中文与英文界面，默认文本随资源语言切换；截图与HTTP结果均已留存。
- 每种语言分别执行1.0→1.2→1.0倍播放，全部完成且错误码0；1.2倍音频时长缩短，恢复1.0后时长一致。
- 空输入、非法语速、越界语速、超长文本均返回400；播放中重复提交返回409，不影响当前任务。
- 本次热点短句：中文RTF0.476～0.502、首PCM219～227ms；英语RTF0.413～0.421、首PCM161～166ms。热点与hello为不同文本/运行环境，不能直接当作同句性能对比。
- 核对SDK版本、默认50%热点音量、资源烧录映射、归档和包内SHA-256。最终整理只更新验证文档及校验信息，应用、预编译库和模型资源不变。
- 验证后恢复原板完整16MiB Flash，通过设备端全量摘要校验并确认原固件启动；电脑原Wi-Fi连接已恢复。

首PCM是生成首段样本的时间，不是扬声器实际首字延迟；RTF为计算耗时/音频时长。
本轮未追加人工音质评审，也未重做30分钟连续播放；历史中文的长期测试不算作本版结果。
