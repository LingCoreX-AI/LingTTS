# 文本支持范围与已知局限（0.2.0-rc1，沿用 PoC 模型）

## 输入

- UTF-8 文本，长度不限。按句末标点（。！？!?… 和换行）切句；一句超过 256 个字时，在 ，、；： 处再切开。
- 简体中文为主；常见繁体字会先转成简体再读。
- 只有标点、空白、表情符号等读不出来的内容不产生音频（`speak` 返回 OK，不回调）。

## 英文

- 26 个字母有固定读音（A 读 ei、W 读 da-bu-liu …），带中文口音。
- 内置读音表约 80 个常用词：hello、ok、sorry、wifi、iphone、android、python 等，以及 LingTTS、xiaozhi 这类产品名。
- 驼峰写法和连字符会拆开查表，例如 ChatGPT → Chat + G P T。
- **表里没有的英文单词逐个字母念**，例如 the → T H E、Bluetooth → B L U E …。

## 已知局限

- **只有一个基础音色**，普通话，16 kHz。定制音色（音色包）的接口已经做好，音色本身还在训练中。
- **英文是中文口音**，只适合夹在中文里的少量字母、缩写和品牌名，不适合读英文句子。
- **英文单位逐个字母念**：240MHz 读成“两百四十 M H Z”，8MB、3.3V 同理。产品里常用的英文单位建议先在文本里换成中文（兆赫、兆字节、伏）。
- **编号类数字按数值读**：“房间号1203”读成“一千二百零三”，不是“一二零三”；“No.007”里的点会被当成句号。
  对读法有要求的号码，可以在文本里先写成汉字或加空格分开。
- **多音字和生僻词**：默认词典是裁剪版，和完整版相比约每 300 句有 1 句读音更差；完整版本身也有少量多音字读错。
  发现读错请把原句反馈给我们，词典可以修正。
- **韵律**：不支持 SSML，不能指定停顿、重音或情感；只能调整整体语速（`cfg.speed`）。
- **长句停顿**：一句超过 256 个字且没有逗号时会被硬切开，切开处会有不自然的停顿。
- **首包延迟**：从调用 `speak` 到第一段 PCM 约 0.3 s，句子越长略多（编码器要先处理整句）。
- **芯片**：只支持 ESP32-S3。
