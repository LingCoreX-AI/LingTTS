# LingTTS: Offline Chinese and English Neural Text-to-Speech for ESP32-S3

[简体中文](README.md) | English

LingTTS is a neural text-to-speech model for offline Chinese and English speech synthesis on ESP32-S3-class devices. It generates speech locally from Chinese or English text, including stories, short passages and device information. The ESP-IDF SDK provides an integration interface.

**Chinese samples:** [short sample](samples/mandarin-short.wav) · [short story](samples/mandarin-story.wav) · [type and synthesize your own text](https://edge.lingcorex.cn/#listen). The WAV samples are generated with LingTTS Voice A. The online demo runs a PC build; use board measurements below for device performance.

## Offline Chinese and English speech synthesis on ESP32-S3

The same LingTTS SDK and engine API generate speech locally on ESP32-S3 using the loaded Chinese or English resources. No cloud connection is needed; the ESP-IDF SDK provides the integration interface.

### Chinese

Synthesizes Mandarin stories, short passages, instructions and device information from Chinese text.

**Listen first:** [Chinese short sample](samples/mandarin-short.wav) · [Chinese story](samples/mandarin-story.wav) · [type Chinese text online](https://edge.lingcorex.cn/#listen). The WAV samples use Mandarin Voice A; the online demo runs a PC build.

- **Resources:** 1.83 MB per voice model, or about 2.38 MB including the trimmed dictionary.
- **Board speed:** hello RTF **0.419–0.440 with PSRAM**, measured on three sentences with this release on ESP32-S3 N16R8.
- **Voices:** Mandarin female A and B. Voice A is the default; Voice B is a separate model resource.

### English

Synthesizes everyday conversations, instructions, stories and short passages with an American English female voice.

**Listen first:** [English short sample](samples/english-short.wav) · [English story](samples/english-story.wav). Both WAV samples were generated from text by an actual ESP32-S3.

- **Resources:** 1.61 MB model plus an approximately 95 KB trimmed dictionary, about **1.71 MB** combined.
- **Board speed:** hello RTF **0.390–0.397 with PSRAM**, measured on three sentences with this release on ESP32-S3 N16R8. A separate full-text test measured median RTF **0.580 without PSRAM**.
- **Voice:** one American English female Voice A. Download the optional English resources and replace the model and dictionary together; hello and web_demo are shared.

The two languages use different test sentences. See [board acceptance](releases/v0.3.0-rc1-validation.md) and [English resource/performance details](docs/英语资源与性能.md) for measurement scope. Lower RTF is faster; values below 1 are faster than real time.

**Offline use and licensing:** both languages synthesize locally. Examples use MIT; the core engine, models and dictionaries use the separate community license. Commercial deployment requires written authorization.

If LingTTS is useful for your ESP32 or embedded speech project, consider starring the repository so you can find it again and help other developers discover it.

## ESP32-S3 performance and memory

The measurements below are historical Chinese 0.2.0 results; see [current board acceptance](releases/v0.3.0-rc1-validation.md) for the shared SDK. The board is ESP32-S3 N16R8 at 240 MHz with ESP-IDF 5.5.6. Results depend on the application and memory configuration. RTF is synthesis time divided by generated audio duration; lower is faster.

| Metric | Measured result |
| --- | --- |
| Audio output | 16 kHz, 16-bit mono PCM, delivered in chunks |
| RTF | 0.42 with PSRAM / 0.48 using internal RAM, hello example including text front end; 0.53–0.54 in the Wi-Fi demo |
| First PCM | 0.27–0.32 seconds from invocation, not speaker playback latency |
| Memory | 2.63 MB PSRAM plus about 1 KB internal RAM, or 151 KB internal RAM without PSRAM; task stack, DMA and application memory are extra |
| Flash | About 2.6 MB for library, one voice model and dictionary; fits within 4 MB Flash subject to application and partition needs |

See the [performance details](docs/资源与性能.md) and [integration guide](docs/集成指南.md) (Chinese).

## Voices

### Chinese voices

Two Mandarin female voices are available: **Voice A** is included in the common SDK and ready-to-flash demo; **Voice B** is distributed as `lingtts-voice-b-1.0.tar.gz` in the [v0.2.0-rc2 Release](https://github.com/LingCoreX-AI/LingTTS/releases/tag/v0.2.0-rc2).

Voice B is a complete model; replace the model resource as described in the [integration guide](docs/集成指南.md). The demo defaults to Chinese Voice A. Keeping both Chinese voices requires an extra model partition, and switching requires recreating the engine.

### English voice

One **American English female Voice A** is available, model version **1.1.0**. Download `lingtts-resources-en-US-1.1.0-community.tar.gz` from the [v0.3.0-rc1 Release](https://github.com/LingCoreX-AI/LingTTS/releases/tag/v0.3.0-rc1).

Upgrade to the common SDK, then [replace the model and dictionary together](docs/英语资源切换.md). No application replacement or changes to hello/web_demo are required. English Voice A and Mandarin Voice A are separate language models. Mixed-language speech and automatic runtime management of two language packages are not supported.

## Try it on a board

The demo requires an ESP32-S3 N16R8 board, MAX98357A amplifier and speaker. Connect BCLK to GPIO 15, LRC to GPIO 16, and DIN to GPIO 7. Download the community demo package from [Releases](../../releases), extract it and run:

```bash
python -m pip install esptool==4.12.0
python flash.py --port COM5  # Linux / WSL: python3 flash.py --port /dev/ttyUSB0
```

Connect a phone to the `LingTTS-Demo` Wi-Fi hotspot (password `lingtts-demo`), open http://192.168.4.1, enter Chinese text, select a speech speed and play it. Defaults are 1.0× speed and 50% playback volume.

For ESP-IDF integration, clone this repository and fetch the versioned binary SDK package with checksum verification:

```bash
# Linux / WSL
./scripts/get-sdk.sh

# Windows PowerShell
.\scripts\Get-LingTTSSdk.ps1
```

Then build from the SDK directory printed by the script, with ESP-IDF 5.5.6 configured:

```bash
idf.py -C examples/hello -B build/hello build
```

The examples and integration files are in this repository. The precompiled component, model and dictionary are distributed in the separately licensed SDK package. See the [Chinese integration guide](https://github.com/LingCoreX-AI/LingTTS/blob/main/docs/%E9%9B%86%E6%88%90%E6%8C%87%E5%8D%97.md).

## Limitations

- Chinese resources do not speak full English sentences; load the separate English resources. Mixed-language speech, SSML and emotion controls are unsupported.
- Polyphonic characters, names and model numbers may be mispronounced.

## Speech speed (0.2.0-rc2)

The hotspot demo offers 0.5–2.0× speech speed (default 1.0×). In the hello example, menuconfig → LingTTS hello → Speech speed percent accepts 50–200.

Set `cfg.speed = 1.2f` before engine creation, or call `lingtts_engine_set_speed(e, 0.8f)` between utterances in the same task that calls `speak`. Speed scales predicted phoneme durations; PCM and I2S stay at 16 kHz.

Board listening at all six speeds and a 30-minute continuous playback test: passed.
